# ShortCuts

یک افزونه کروم برای نمایش و مدیریت میانبرهای مفید کروم و ویندوز با قابلیت جابجایی و اولویت‌بندی.

## ویژگی‌ها

- لیست ضروری میانبرهای کیبورد کروم
- میانبرهای ویندوز
- قابلیت جابجایی و مرتب‌سازی
- اولویت‌بندی میانبرها
- رابط کاربری ساده و کاربرپسند

## نصب

1. این مخزن را کلون کنید:
   ```bash
   git clone https://github.com/ProPersian/ShortCuts.git
   ```

2. به پوشه پروژه بروید:
   ```bash
   cd ShortCuts
   ```

3. در مرورگر کروم:
   - به آدرس `chrome://extensions/` بروید
   - گزینه "Developer mode" را فعال کنید
   - روی "Load unpacked" کلیک کنید
   - پوشه پروژه را انتخاب کنید

## ساختار پروژه

- `manifest.json` - فایل مانیفست افزونه
- `popup.html` - صفحه اصلی پاپ‌آپ
- `popup.js` - کدهای جاوااسکریپت پاپ‌آپ
- `popup.css` - استایل‌های CSS
- `createIcon.html` - صفحه ایجاد آیکون
- `icon*.png` - آیکون‌های افزونه

## مشارکت

اگر می‌خواهید در توسعه این پروژه مشارکت کنید، لطفاً:

1. یک فورک از پروژه ایجاد کنید
2. تغییرات خود را در یک شاخه جدید اعمال کنید
3. یک Pull Request ارسال کنید
